# knowledge Knowledge Base

> Divided into two categories by use: **Automatic Injection** and **Discussion with Author**.

## Categories

| Directory | Purpose | Decision Maker |
|-----------|---------|----------------|
| `scene-craft/` | Scene Writing Methodology — Automatic Injection into Output·Writing Guidelines | **AI Automatic**, no author needed |
| `format-specs/` | Formatting Specifications — Defining file structure | Fixed by system |
| `genre-example/` | Genre Examples — Inherited into the project | Automatic after genre is decided |
| `plot-craft/` | Plot Design Methodology — Displayed for author to choose | **Author Decision** |
| `character-craft/` | Character Setting Methodology — Displayed for author to choose | **Author Decision** |
| `title-craft/` | Book Naming Methodology — Displayed for author to choose | **Author Decision** |
| `anti-ai/` | Anti-AI Rules (categorized by genre) — Reference to remove AI flavor | **AI Automatic**, no author needed |

## Rules

- **Automatic Injection Category** (`scene-craft`): Do not ask the author; match automatically by scene type, and inject into the Output·Writing Guidelines after a four-step transformation.
- **Discussion Decision Category** (`plot-craft` / `character-craft` / `title-craft`): The Agent displays options for the author to choose and cannot decide on its own.
