# Genre Setting Guide

> Genre is the first step of Phase 2 — determine the genre before discussing the worldview and characters. After selection, write it into `settings/genre-setting.md`.
> There are 5 fields in total: Selected Genre / Satisfaction Types / Pacing Rules / Avoid Tropes / Genre Taboos. Discuss and write them one by one.

---

## Select Genre First

This step is not a field written into the file; it's a prerequisite for discussing other fields — once the genre is set, you know what aspects to discuss.

### How to Discuss: Let the Author Tell the Story, You Judge

Do not throw a classification list at the author. At this stage, the author definitely has something they want to write, but they might not know the terminology. Ask directly:

> "What kind of story do you roughly want to write? Don't worry about genre classification, just tell me who the protagonist is, what kind of world they are in, and what they do."

**Regardless of what the author says, do two things after listening:**

1. Extract **3 key signals** from the author's description — era background, power system, and core conflict type.
2. Use the table below to determine the most matching genre.

| Key Signals | Matching Genre |
|---------|---------|
| Modern Urban + Daily Emotion + Real Life | Urban Daily |
| Modern Urban + Golden Finger System + Brain Hole (Imaginative) | Urban Brain Hole |
| Modern Urban + Farming/Building + Business/Workplace | Urban Farming |
| Modern Urban + Universal Cultivation + Spiritual Energy Revival | Urban High Martial Arts |
| Modern Urban + Immortal Cultivation/Comprehension System | Urban Cultivation |
| Modern Urban + God of War Returns + Matrilocal Husband Turnaround | God of War / Matrilocal Husband |
| Ancient Background + Farming/Court/Hegemony | Historical Ancient |
| Ancient Background + Golden Finger + Brain Hole | Historical Brain Hole |
| Anti-Japanese War Era + Military/Espionage | War/Espionage |
| Another World Continent + High Martial Arts + Loser Counterattack | Traditional Fantasy |
| Another World Continent + Brain Hole Setting | Fantasy Brain Hole |
| Modern + Investigation/Reasoning/Criminal Investigation | Suspense/Criminal Investigation |
| Modern + Supernatural/Feng Shui/Horror | Suspense/Supernatural |
| Weird Revival + Rule Ghost Stories + Thriller Games | Suspense Brain Hole |
| Apocalyptic/Zombies/Interstellar/Mecha/Future Tech | Sci-Fi/Apocalyptic |
| Western World + Magic/Battle Qi/Fantasy | Western Fantasy |
| Eastern World + Immortal Cultivation/Dao/Comprehension | Eastern Xianxia |
| Film/TV Drama Fanfiction Adaptation | Male-oriented Derivative |
| Game/Anime/2D Fanfiction | Anime Derivative |
| Online Games/Esports/Sports/World Gamification | Game/Sports |

**After judging, show it to the author for confirmation:**

> "It sounds like you are writing **{Genre}** — {one-sentence reason}. Is that right?"

✅ Correct:
> Author: "I want to write about an ordinary office worker who suddenly can see the death countdowns over people's heads. He tries to save them, but finds the countdowns get shorter."
> → Signal Extraction: Modern Urban (office worker) + Golden Finger System (death countdown) + Backlash for saving people
> → Judgment: **Urban Brain Hole (urban-brained)**
> → Confirmation: "It sounds like you are writing Urban Brain Hole — a modern urban background, the protagonist gets a special ability, but this ability has a price. Is that right?"

❌ Incorrect:
> Author: "I want to write a story." → Continue asking: "What kind of person is the protagonist? Where does the story take place? Ancient or modern?"

**Conditional Branches:**

| Author Says | How to Respond |
|--------|--------|
| "Yes, exactly that" | Proceed to Field 1, write the selected genre |
| "Not quite, more like XX" | Re-evaluate based on the author's correction, or select manually |
| "I still don't know what genre it is" | "That's fine. Does your story have supernatural powers? Ancient or modern? — Once these are set, it's easier to classify." |
| "I don't want to choose a genre" | "The genre needs to be set before discussing the worldview — the worldviews of Xianxia and Post-Apocalyptic are completely different. Set the genre first so the worldview discussion is accurate." "Temporarily skip" is also valid, can be added anytime. |

**Judgment Standard:** Did the author clearly state a genre (or "temporarily skip")? If ambiguous → continue discussing.

**No need to read external files.** Each field below has inline multi-genre examples; reference them directly.

## Field 1: Selected Genre

**What to Write:** Genre id + English/Native name, one line.

```
xianxia — Eastern Xianxia
```

Use lowercase English with hyphens for the id, and the author-approved expression for the name. If selecting a fusion genre, mark the main genre + overlapping elements:

```
urban-brained — Urban Brain Hole (with Suspense/Investigation elements)
```

**Judgment Standard:** Reading it tells you what genre it is and what elements are fused.

## Field 2: Satisfaction Types

**What to Write:** 3-5 types of "satisfaction" readers want from this genre, each described in one sentence regarding its core appeal.

### Underlying Model: Repression → Acquisition → Release → Repression Again

All genres share the same underlying loop for satisfaction. Clearly state how different genres simply change the skin of this loop:

```
Repression (looked down upon/lack of resources/at the bottom)
  → Acquisition (encounter/breakthrough/key clue/ally)
    → Release (face-slapping/showing off/plot twist/solving the case)
      → Repression Again (stronger opponent/new mystery/higher-class enemy)
        → Loop...
```

Skipping "Repression" and jumping straight to "Acquisition" will not feel satisfying to the reader — without contrast, there is no satisfaction. Skipping "Repression Again" will make the reader feel the story is ending — no motivation to keep reading.

**Different genres simply change the skin of this loop:**

| Genre | Repression Phase (What's Missing) | Acquisition Phase (What's Gained) | Release Phase (How it Satisfies) | Repression Again (New Pressure) |
|------|------------------|-------------------|------------------|----------------|
| Eastern Xianxia | Poor spiritual root/Few resources/Looked down upon | Heavenly treasures/Technique/Breakthrough | Realm crush/Face-slapping | Higher realm/Sect politics |
| Urban Brain Hole | Ordinary worker/No money or power | Golden finger/Ability awakening | Showing off/Counterattack | Stronger ability users/Organizations |
| Suspense Investigation | Clues cut off/Deceived/Misled | Key evidence/Breakthrough point | Reasoning solves case/Plot twist | Bigger conspiracy/New mystery |
| Historical Ancient | Suppressed by political enemies/Tight finances | Talents/Resources/Emperor's favor | Court turnaround/Reforms work | New factions/External threats |
| Urban Daily | Workplace trouble/Relationship conflict | Turning point/Benefactor/Realization | Conflict resolved/Relationship warms | New problems/New conflicts |

**Therefore, when discussing, don't ask "What are the satisfying points?", ask:**

> "In your genre, what does the reader most want to see the protagonist escape from, obtain, and achieve?"
>
> — Escape from = Repression phase, Obtain = Acquisition phase, Achieve = Release phase.

**Judgment Standard:** Can each satisfaction type clearly state the corresponding "Repression → Acquisition → Release" three phases? If not → Missing repression means the reader won't feel satisfied.

## Field 3: Pacing Rules

**What to Write:** Three rules — pacing tendency, tension cycle, build-up limit.

### Pacing Tendency

Is this chapter advancing the plot or building atmosphere? Looking at a whole volume, is it tense throughout or does it alternate between tense and relaxed? This doesn't dictate how every single chapter is written, but it sets the overall pacing feel of the volume. Describe it in one sentence; precise measurement isn't needed.

| Tendency | Meaning | Suitable For |
|------|------|------|
| Action-heavy | Conflict/Battle/Confrontation dominant, fast-paced | Satisfying reads, hot-blooded, fast upgrades |
| Build-up-heavy | Information laying/Atmosphere/Daily life dominant, slow-paced | Suspense, slice-of-life, slow burn |
| Alternating | A chapter of breathing room after a few tense chapters | General for most genres |
| Tense Throughout | Almost no daily life or buffer | Infinite flow, apocalyptic, high suspense |

**How to Discuss:**
> "Is your story's pacing generally fast or slow? — How many chapters until a minor climax? Is it acceptable to have several chapters of build-up with no advancement?"

### Tension Cycle

How many chapters for a minor climax, how many for a major climax.

**Patterns:**
- Satisfying read: 3-5 chapters minor climax, 10 chapters major climax
- Suspense: 4-6 chapters minor climax, 15 chapters major climax
- Daily life: 5-8 chapters minor climax, 20 chapters major climax

### Build-up Limit

"Maximum consecutive chapters without progress." Exceeding this limit will cause readers to drop the book.

**Reference Range:** Fast-paced 2 chapters, Medium 3 chapters, Slow burn 4 chapters.

✅ Correct (Xianxia Fast-paced):
> - Pacing Tendency: Action-heavy
> - Tension Cycle: Minor climax every 3-5 chapters, major climax every 10 chapters
> - Build-up Limit: Maximum 2 consecutive chapters of build-up; the 3rd chapter must have progress

✅ Correct (Suspense Slow Burn):
> - Pacing Tendency: Build-up-heavy
> - Tension Cycle: Minor climax every 4-6 chapters, major climax every 15 chapters
> - Build-up Limit: Maximum 3 consecutive chapters of build-up; the 4th chapter must advance events

❌ Incorrect:
> Pacing is moderate, fast when it should be fast, slow when it should be slow — Saying this means nothing.

**Judgment Standard:** If an agent reads this, will they "know it but not know how to execute it"? If yes → Not specific enough.

## Field 4: Avoid Tropes

**What to Write:** Clichés in this genre that readers are tired of. ≥3 items.

Tropes aren't forbidden, but they shouldn't be written unconsciously. Before writing, you must know "this is a trope," and then decide whether to subvert it, bypass it, or acknowledge it but write it better.

**How to Discuss:**
> "Are there any tropes in this genre you don't want to write? — The kind where you know the ending just by looking at the beginning."

What the author lists might need refining:

| Author Says | Write As |
|---------|------|
| "I don't want the old auction face-slapping" | Auction means guaranteed showing off and face-slapping |
| "No jumping off cliffs for miraculous encounters" | Protagonist jumps off a cliff and inevitably gets a miraculous encounter |
| "I don't want the protagonist to be invincible right away" | Protagonist awakens as S-class immediately |

✅ Correct:
> Protagonist jumps off a cliff and inevitably gets a miraculous encounter — Jumping off a cliff doesn't guarantee a miraculous encounter; it might just be an ambush.

❌ Incorrect:
> Don't write tropes — Too broad, what counts as a trope?

**Examples per Genre (Direct Reference):**
- Xianxia: Jumping off cliffs for encounters, auction face-slapping, looked down upon during entrance tests, high realm hiding strength to shock the crowd
- Urban Brain Hole: Protagonist awakens as S-class, government agencies are all useless, ability users are too poor to eat, female characters only get hurt and rescued
- Suspense Investigation: First witness is the killer, the most impossible killer, genius detective sees through everything at a glance, final boss is always an acquaintance

**Judgment Standard:** Could each item be included in a 5-minute "web novel trope complaint" video? If yes → Pass.

## Field 5: Genre Taboos

**What to Write:** Things that absolutely must not appear in this genre — if written, readers will drop the book and the genre falls apart.

Taboos are not optional "try to avoid" things; they are things that ruin the flavor of the whole book if included.

**Common Taboos Fall into Three Categories:**

| Category | Meaning | Example |
|------|------|------|
| System Collapse | Self-consistency is broken | Power levels fluctuate wildly, cultivation reaches the top in one step, magical treasures do whatever you want |
| Genre Mismatch | Things appear that shouldn't belong in the genre | Xianxia world talking about universal equality, modern values in ancient times |
| Broken Promises | Core experience is destroyed | Mystery novel uses supernatural means to solve cases, apocalyptic novel has no survival pressure |

**How to Discuss:**
> "What do you think is absolutely forbidden to write in this genre? — The kind of thing that makes readers curse 'what the hell is this' if written."

If the author can't name any, give examples based on the selected genre:

> "In Xianxia, power level collapse is a common minefield — do you mind that? What about modern values randomly appearing in the cultivation world?"

✅ Correct (Xianxia):
> - Forbid power system collapse — Power levels cannot fluctuate wildly for plot convenience.
> - Forbid modern values invading the cultivation world.

❌ Incorrect:
> Don't write too outrageously — What counts as outrageous? Who defines it?

**Examples per Genre (Direct Reference):**

| Genre | Common Taboos |
|------|---------|
| Eastern Xianxia | Power level collapse, cultivation reaching the top in one step, modern values invading, magically convenient treasures, heavenly tribulations just for show |
| Urban Brain Hole | Abilities without costs, government completely ignorant, protagonist is omniscient and omnipotent, system logic is inconsistent |
| Suspense Investigation | Supernatural problem solving (in non-supernatural genres), forced killer motives, clues appearing out of thin air, villains acting stupid |
| Historical Ancient | Modern ideologies time-traveling, technology jumping too fast, historical figures being one-dimensional, golden fingers too strong without restriction |

**Judgment Standard:** Can the author imagine "what it looks like if this taboo is violated"? If not → Too abstract.

## Writing to File

Write to `settings/genre-setting.md`, Markdown format. Complete format reference:

```markdown
# Genre Setting

## Selected Genre
xianxia — Eastern Xianxia

## Satisfaction Types
- Realm Breakthrough (Hard power leap)
- Secret Realm Treasure Hunt (Resource scramble)
- Face-Slapping Counterattack (Strength crush followed by reversed evaluation)
- Grand Dao Contention (Ideological conflict vs. strength showdown)

## Pacing Rules
- Pacing Tendency: Action-heavy
- Tension Cycle: Minor climax every 3-5 chapters, major climax every 10 chapters
- Build-up Limit: Maximum 2 consecutive chapters of build-up; the 3rd chapter must have progress

## Avoid Tropes
- Protagonist jumps off a cliff and inevitably gets a miraculous encounter
- Auction means guaranteed showing off and face-slapping
- Looked down upon during entrance tests

## Genre Taboos
- Forbid power system collapse
- Forbid cultivation reaching the top in one step
- Forbid modern values invading the cultivation world
```

## How Each Field is Used Downstream

Writing to `settings/genre-setting.md` is not the end; each field has a corresponding consumption stage. Agents must read the corresponding fields when writing direction proposals/chapter outlines/prompts, otherwise writing it is useless:

| Field | Who Uses It | How It Is Used |
|------|------|--------|
| Selected Genre | `prompt-crafter agent` assembling prompts | Reads genre_profile, fetches `prompt_segment` from `knowledge/genre-example/` to inject into prompt |
| Satisfaction Types | `chapter-planner agent` direction proposal | The chapter proposal must deliver at least 1 satisfaction type; if a segment delivers none = readers waited a chapter for nothing |
| Pacing Tendency | `chapter-planner agent` direction proposal | Controls the number of consecutive chapters of the same type (e.g., "action-heavy" still can't have 3 consecutive high-climax chapters, readers will get fatigued) |
| Tension Cycle | `updater-archive skill` sliding window review | If exceeding the tension cycle limit without a minor climax → Reminds the author "Pacing might be at risk" |
| Build-up Limit | `chapter-planner agent` direction proposal | When consecutive build-up chapters approach the limit, the proposal must push a direction with progress |
| Avoid Tropes | `writer agent` quality gate | Checks if the text hits patterns in the avoid_cliches list |
| Genre Taboos | `prompt-crafter agent` assembling prompts | Taboos are written into the "Writing Principles and Taboos" section of the prompt; subagents must not violate them |

**Rule:** If any of the above fields are empty or only have placeholder values, the Agent in the corresponding consumption stage will make its own judgment without constraints. If a chapter feels wrong, first check "Did the consumption stage read genre-setting.md?".

## Acceptance: Working Backwards from Downstream Use

Acceptance isn't looking at "whether it was written", it's looking at "can downstream use it". Verify each field by simulating a consumption scenario:

### Selected Genre

| Acceptance Method | How to Verify |
|---------|--------|
| Is it there? | Has a genre id or "Temporarily no selection", non-empty |
| Should it be? | Confirmed by the author, not guessed by the Agent |
| Is it correct? | Later, the `prompt-crafter agent` needs this id to find the corresponding file in `knowledge/genre-example/`. If the id is wrong, it can't find it. → Verification: Check if the corresponding file exists in knowledge/genre-example/ |

### Satisfaction Types

| Acceptance Method | How to Verify |
|---------|--------|
| Are they there? | ≥ 3 items |
| Should they be? | Each item is a specific description of appeal, not abstract tags like "satisfying" or "hot-blooded" |
| Are they correct? | The **direction proposal stage** uses these 3-5 items to judge "which satisfaction type this chapter delivers". If an item is too broad ("hot-blooded"), the Agent won't be able to say "does this chapter satisfy this item or not" when judging direction. → Verification: Pick an item, ask "What content in this chapter counts as delivering this item?" If answerable → Pass |

### Pacing Rules

| Acceptance Method | How to Verify |
|---------|--------|
| Are they there? | Pacing tendency + tension cycle + build-up limit all have values |
| Should they be? | All three are specific, executable descriptions, not "fast when it should be fast" |
| Are they correct? | **Sliding window review** uses pacing tendency to judge if actual pacing deviates from expectation. **Direction proposal** uses build-up limit to avoid exceeding consecutive build-up limits. If the tension cycle says "minor climax every 3-5 chapters" but actually there hasn't been one for 8 chapters, it should catch the deviation. → Verification: Read the chapter titles and emotional states of the last 5 chapters, compare and ask "Did it deviate from the pacing tendency?" |

### Avoid Tropes

| Acceptance Method | How to Verify |
|--------|--------|
| Are they there? | ≥ 3 items |
| Should they be? | Each item is a specific plot device ("jump off cliff get encounter"), not a broad concept ("no tropes") |
| Are they correct? | The **text quality gate** uses this list to scan the text. If an item is written as "don't write too cliché", the scanning script can't judge "what counts as cliché" even if it searches the whole text. → Verification: Show the list to someone; can they point out "this piece of text hits this trope"? |

### Genre Taboos

| Acceptance Method | How to Verify |
|--------|--------|
| Are they there? | ≥ 2 items |
| Should they be? | Each item should allow imagining what violating it looks like, not "don't write too outrageously" |
| Are they correct? | **Prompt assembly** writes taboos into the "Writing Principles and Taboos" section. If an item says "forbid system collapse", the subagent won't know "what constitutes collapse" after reading. → Verification: Rewrite into a form the subagent can judge — "Forbid power levels fluctuating wildly: If previous text said Golden Core can't beat Foundation Establishment, this chapter cannot write Foundation Establishment instantly killing Golden Core" |
